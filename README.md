# E-Commerce API Testing Project

## Project Overview
This project focuses on manual API testing of e-commerce APIs using Postman. It covers positive and negative scenarios for Products, Authentication, and Carts APIs.

## Tools Used
- Postman
- Excel
- GitHub
- DummyJSON API

## APIs Tested
- **Products API:** Retrieve products, search, categories, pagination, and sorting.
- **Authentication API:** Login, token validation, and token refresh.
- **Carts API:** Retrieve, add, update, and delete carts.

## Testing Activities
- Positive and negative testing
- HTTP status code verification
- Response body validation
- Pagination and sorting validation
- Authentication and token validation
- Test case documentation
- Potential defect identification and reporting

## Project Files
- `E-Commerce_API_Test_Cases_v2.xlsx — Test cases and execution results.
- `Carts_API_Bug_Reports.xlsx — Potential defects identified during testing.
- Postman collection JSON — Saved API requests.

## Important Note
This project uses DummyJSON, a mock API service. Data modification operations may be simulated and may not persist permanently. Potential defects require validation against expected requirements before being treated as confirmed bugs.
